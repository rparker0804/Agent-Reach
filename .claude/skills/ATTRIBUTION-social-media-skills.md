# social-media-skills

Source: https://github.com/charlie947/social-media-skills
Author: Charlie Hills
License: MIT (see LICENSE-social-media-skills)

18 skills vendored. Only the `skills/` directory is included — the repo's own
validator (`validate-skills.sh`) and test script were not vendored.

Most of these are LinkedIn-oriented. The ones relevant to CalmedWord:
  reels-scripting   — reference Reel -> your own script
  hook-generator    — hook variations (retention is the known bottleneck)
  niche-research    — surface recent stories in a niche
  post-scorer       — scores posts; expects Apify for post history
  voice-builder     — builds a voice profile from samples
